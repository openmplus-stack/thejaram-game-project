파리바게트에 갔어요

빵을 고르고, 주문하고, 계산하는 순서를 연습해 보아요.

1. 빵집에는 무엇이 있을까요?

빵을 고르고 계산할 때 사용하는 물건과 장소를 골라 보세요.

2. 무엇을 살까요?

“크루아상과 우유를 사요.” 필요한 상품을 골라 보세요.

3. 몇 개 살까요?

크루아상 2개, 우유 1개가 필요합니다.

4. 어떤 순서로 할까요?

빵집에서 하는 행동을 순서대로 정해 보세요.
처음에는 쟁반과 집게를 준비하고, 마지막에는 계산하고 상품을 받아요.

5. 주문해요

직원: “어떤 상품을 계산해 드릴까요?”
상품 이름 + 수량 + “주세요”를 넣어 보세요.

6. 포인트 적립 질문

직원: “포인트 적립하시겠어요?”

7. 계산을 마쳐요

직원이 묻는 질문에 알맞게 대답해 보세요.

8. 이런 일이 생기면 어떻게 할까요?

예상하지 못한 상황에서 알맞은 행동을 골라 보세요.
