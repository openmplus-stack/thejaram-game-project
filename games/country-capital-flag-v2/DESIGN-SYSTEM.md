## 발견한 불일치 원인

1. `style.css`의 학습 유형 화면은 `screen-topic-select.jpg`를 화면 전체 배경으로 사용하는 완성형 이미지 기반 화면이다.
2. 국가 선택 화면은 여러 이미지와 HTML 텍스트를 조합한다.
3. `design-refresh.css`에 국가 화면에 대한 CSS 덮어쓰기 규칙이 누적되어 있다. 후순위 선언이 앞선 선언을 덮으므로 관리가 어렵다.
4. 탐험가 파일을 `explorer-point.png`와 `explorer-master.png` 사이에서 바꾸었지만, 기준 화면과 실제 얼굴·자세·여백이 동일한지 확인하지 않았다.

## 2단계 개발 원칙

1. 원본 자산을 실제 화면과 **육안 대조**해 기준 캐릭터·간판·하단 메뉴를 하나씩 확정한다. 필요하면 승인된 완성 이미지에서 공통 요소를 별도 투명 PNG로 제작하되, 먼저 기존 자산을 검증한다.
2. 공통 프레임(배경, 캐릭터, 제목판, 제목 타이포그래피, 하단 메뉴)을 단일 컴포넌트/공통 CSS로 구현한다. 화면별 CSS에 같은 요소를 중복 작성하지 않는다.
3. 화면 콘텐츠(국가 목록, 학습 이분할 카드, 원형 O/X)는 프레임 내부에 독립적으로 배치한다.
4. 4:3 아이패드 가로 기준으로 실제 캐릭터 보이는 높이와 발 위치, 제목판 크기, 메뉴 크기를 측정하고 고정한다.
5. 국가 선택 목록, 선택/해제, 다음 단계, 학습 10문항, 퀴즈 20문항, 결과·보상 동작은 유지한다.
6. 기존 CSS를 계속 덧붙이는 방식을 중단하고, 확인된 규칙으로 정리한 뒤 Safari 스크린샷으로 승인받는다.
