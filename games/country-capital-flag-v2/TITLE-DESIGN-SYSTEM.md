# 세계 짝꿍 찾기 V2 — 제목판 단일 마스터 규격

## 원본과 수정 범위
- **유일한 시각적 마스터**: 승인된 `assets/screen-topic-select.jpg`의 **학습 방식 선택** 제목판.
- **수정 대상**: 국가 선택, 대륙 선택. 학습 방식 선택의 승인된 화면은 그대로 유지한다.
- 세 화면에서 바뀌는 요소는 **제목 문구만**이다. 배경, 캐릭터, 카드, 국가 데이터, 학습 로직, 버튼은 수정하지 않는다.
- `main`과 `games/country-capital-flag/`는 변경하지 않는다.

## 나무판 — 하나의 실제 이미지 재사용
1. 마스터 화면에서 글자가 없는 나무판 원본을 확인한다. `assets/ui-title-sign.png`가 승인된 이미지와 **실제로 동일한지** 대조한다. 이름만 같다고 동일하다고 가정하지 않는다.
2. 다르면 승인된 마스터와 같은 나무판을 **한 번만** 준비하여 공통 자산으로 사용한다. 기존 승인 파일을 덮어쓰지 않는다.
3. 국가 선택과 대륙 선택에서 **동일한 파일 경로**를 참조한다.
4. 판자 개수·곡률·나뭇결·황금색·나사·좌우 잎·외곽선·그림자·비율을 변경하지 않는다.
5. 나무판에 기존 글자가 이미 포함되어 있다면, 그 위에 새 글자를 겹쳐 덮지 않는다. 글자 없는 마스터가 필요하다.

## 글자 — 동일한 제작 규격
- 매우 굵고 둥근 한글, 일정한 획 굵기, 부드러운 획 끝과 동일한 글자 내부 공간.
- 기준 화면에서 추출한 초콜릿 갈색 채움, 크림색 외곽선, 어두운 경계, 입체 두께와 하단 그림자.
- **CSS font-family, text-shadow, -webkit-text-stroke로 대체하지 않는다.**
- 글자만 있는 **실제 알파 투명 PNG**를 제작한다. 원본 비율을 유지하며 가로로 찌그러뜨리지 않는다.
- `assets/title-country-select.png` — 국가 선택
- `assets/title-continent-select.png` — 대륙 선택
- 기준 학습 방식 선택은 현재 승인된 이미지 그대로 유지한다.

## 앱 구조와 중복 방지
- 공통 나무판 이미지 1개 + 화면별 제목 글자 PNG 1개.
- 제목 이미지 렌더링 경로는 **하나만** 사용한다. HTML 글자, CSS `content`, `::before`, `::after`, background-image 및 JS 추가 요소를 모두 확인한다.
- `aria-label`은 유지한다.
- 국가 선택의 기존 `title-country-select.svg`가 남아 있으면 PNG 적용과 동시에 **기존 SVG 렌더링 경로를 제거**한다.
- 변경된 CSS/이미지 URL의 캐시 버전을 갱신한다.

## 검수와 적용 순서
1. 승인된 학습 방식 선택 제목을 기준으로 세 이미지를 같은 크기로 비교한다.
2. 공통 나무판 자산이 실제로 동일한지 픽셀 또는 투명도·시각 비교로 확인한다.
3. 두 글자 PNG의 알파 채널, 외곽선·그림자·자간·비율을 검수한다.
4. **국가 선택에 우선 적용하고 화면 캡처로 확인**한다.
5. 승인 후 대륙 선택에 적용한다. 다른 화면은 별도 승인 없이 변경하지 않는다.
6. Cloudflare **Preview**에서 아이패드 4:3 기준 제목 중복·잘림·다른 기능의 회귀를 확인한다.

## 현재 상태
이 문서는 공통 제목판 제작·적용의 **확정 규격**이다. 이미지 파일이 실제 생성·커밋되고 Preview에서 검수되기 전에는 구현 완료로 표시하지 않는다.
